# Doctor Yachts — design versions

These are the **last 4 visual directions** we built. Open the HTML files in your browser to compare.

| Version | File | Style | Feel |
|---------|------|--------|------|
| **v1** | `v1-luxury-navy.html` | Navy + gold, luxury marketing | High-end template (you said “AI”) |
| **v2** | `v2-workshop-logbook.html` | Paper + rust + mono stamps | Workshop / logbook |
| **v3** | `v3-local-shop.html` | White + yellow CTA, Georgia | Simple local mechanic shop |
| **v4** | `v4-chart-clinic.html` | Chart cream + teal + coral | **Current live app** — “boat doctor” |

## How to open

Double-click any file, or from the project folder:

```bash
start design-versions\v1-luxury-navy.html
start design-versions\v2-workshop-logbook.html
start design-versions\v3-local-shop.html
start design-versions\v4-chart-clinic.html
```

## Live Next.js app

The running site at `http://localhost:3000` is **v4** (full multipage app).

To switch the real app to another full version later, ask to restore **v1**, **v2**, or **v3** onto the codebase (or keep v4).
